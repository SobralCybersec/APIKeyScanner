# API Key Scanner Release Notes

## 1.0.0

- Rust CLI scanner with bounded GitHub search and repository concurrency.
- Aho-Corasick prefilter plus parallel regex detection.
- Public metadata output separated from ignored private findings.
- Interactive launcher and terminal UI.
- Optional provider validation.

See `CHANGELOG.md` for unreleased changes and `docs/release.md` for the
verification procedure.
